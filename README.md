# 💰 Plan_My_Pocket

A simple and user-friendly **personal expense tracker and group expense splitter** built to help users manage their daily expenses and shared expenses with friends.

## 🚀 Live Demo

[Plan_My_Pocket](https://plan-my-pocket.onrender.com)

## ✨ Features

- 🔐 User Signup and Login
- 💸 Add and manage personal expenses
- 📊 Dashboard with expense summaries
- 🏷️ Expense categories
- 👥 Create and manage expense groups
- 💰 Split shared expenses between group members
- 🧮 Automatic settlement calculation
- 📱 Responsive and clean interface

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Data Storage:** JSON
- **Authentication:** Password hashing with Node.js Crypto
- **Deployment:** Render
- **Version Control:** Git & GitHub

## ⚙️ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/Sruthi-Mariam-Shaji/Plan_My_Pocket.git
cd Plan_My_Pocket
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the server

```bash
node server.js
```

### 4. Open the application

Visit:

```text
http://localhost:5000
```

Plan_My_Pocket was developed as a full-stack web project to practice **web development, backend APIs, authentication, expense management, and deployment**.
